# Enterprise Network Troubleshooting Lab (Cisco Packet Tracer)

## Overview
This project simulates a small enterprise network using Cisco Packet Tracer. It focuses on practical troubleshooting of common network issues like IP configuration errors, gateway issues, and link failures.

## Objectives
- Understand basic enterprise network structure
- Practice IP addressing and gateway configuration
- Identify and fix common network connectivity issues
- Apply basic troubleshooting using ping and interface checks

## Tools Used
- Cisco Packet Tracer
- TCP/IP Networking
- IP Addressing & Subnetting
- Ping Command
- Router & Switch Configuration

## Troubleshooting Scenarios

### 1. Incorrect Default Gateway
- Issue: Devices unable to reach external network
- Cause: Wrong gateway configuration
- Fix: Updated correct default gateway
- Result: Network connectivity restored

### 2. Router Interface Down
- Issue: No communication between network segments
- Cause: Router interface was administratively down
- Fix: Enabled interface using "no shutdown"
- Result: Inter-network communication restored

### 3. Cable Disconnection
- Issue: Device not responding in network
- Cause: Physical link disconnected
- Fix: Reconnected cable to correct port
- Result: Device communication restored

## Skills Demonstrated
- Network troubleshooting
- IP configuration
- Router interface management
- Problem diagnosis using ping
- Logical debugging of network issues

## Outcome
Gained practical understanding of enterprise network troubleshooting and basic network administration concepts.
